# PRD — AI 助手（独立悬浮组件）v2

> 状态：生效（2026-09-10）。v1 的"工具栏按钮 + 悬浮窗切 AI 模式"方案在设计评审中推翻，
> 重构为独立三态组件：**左下角圆钮 → 极简输入框 → 展开面板**，笔记窗完全不参与。
> 待澄清问题已全部清空（四项拍板：圆钮常驻透明可调、多轮对话、笔记窗自动收起、v1 无语音用发送键）。

## 一句话定位

独立于笔记窗的悬浮 AI 助手：竖条依旧随手记，左下角圆钮随手问，问完即收，回答可回流为笔记。

## 目标用户与场景

- 用户自备 API Key（BYOK），OpenAI 兼容接口 + 自定义 Base URL（DeepSeek / 智谱 / 通义 / OpenAI / 局域网本地模型）
- 场景 1（随手问）：任意 App 里遇到看不懂的 → 点左下角圆钮 → 输入框直接问 → 收起继续读
- 场景 2（碎片整理）：口语化乱输入或点「整理这篇」→ AI 返回结构化文本 → 存为笔记
- 场景 3（笔记问答）：＋ 菜单插入当前笔记作上下文，总结 / 翻译 / 追问

## 核心循环

点悬浮窗左下角 AI 按钮（与右下缩放手柄对角）→ 窗口收为竖条、极简输入框**在悬浮窗原位**浮现（下方建议气泡）→ 输入发送（可立即收起，后台续生成）→ 输入框**原位绽放**为面板、流式显示回答（等待期三点动画）→ 底部输入框继续追问（多轮）／＋ 新建会话 → ✕ 收起（点竖条回来）→ 有价值则存为笔记。

约束铁律：**笔记窗"点竖条→写→收起"路径零变化；AI 是独立组件，不碰笔记窗内部。**

## Must 功能完整描述

### 功能名：AI 圆钮（入口）

- 正常流：常驻屏幕左下角（边距约 16dp，避开手势区）；半透明深色圆 + 白色 AI 图形；点击 → 圆钮隐去、输入框在其上方浮现。
- 边界情况：透明度设置（默认低调约 35%）；设置页"AI 按钮"总开关；后台生成中圆钮角落呼吸点提示；旋转 / 分辨率变化重新钳位在左下角。
- 异常流：未配置时首次点击 → 弹最小配置表单，可取消，取消后停留圆钮态。
- 依赖：前台服务（新 overlay 挂现有 FloatingNoteService，不新建服务）。

### 功能名：极简输入框与建议气泡

- 正常流：大圆角胶囊（浅色纯白 / 夜间深灰），靠柔和弥散阴影浮起；左「＋」、中占位"输入你的问题…"、右发送键；下方一排建议气泡：整理这篇 / 解释 / 翻译 / 总结。点建议 = 发送预设指令（整理这篇 / 总结携带当前笔记正文；解释 / 翻译作用于输入框文本），发起后气泡隐藏。
- 边界情况：输入框 1~4 行自动增高；空输入禁发；当前无笔记 → 整理这篇 / 总结置灰；收起时未发送文字保留为草稿（下次点圆钮回填）。
- 异常流：点输入框外区域 → 收起回圆钮（草稿保留）。
- 依赖：新建组件的 IME 避让（逻辑参照笔记窗既有实现）。

### 功能名：展开面板（多轮对话）

- 正常流：发送瞬间输入框原位展开为面板（约 85% 屏宽 × 自适应高度，圆角与弥散阴影同风格）；用户消息浅灰气泡右对齐，AI 回答无气泡纯文本流式输出（尾部光标闪烁）；面板底部停靠同款输入栏可继续追问；右上「✕」收起回圆钮。
- 边界情况：多轮上下文携带最近 N 轮（技术方案定）；生成中收起不中断生成（圆钮呼吸点）；长回答滚动；图片消息在流内显示缩略图；生成中发送键置灰。
- 异常流：App 被杀 → 当前会话丢失（v1 接受，历史列表属 Should）。
- 依赖：AiChatClient（已实现）、笔记窗自动收起。

### 功能名：笔记窗自动收起

- 正常流：AI 输入框或面板出现时，若笔记窗处于展开态 → 走既有收起动画收为竖条；AI 收起后竖条停留原处不自动弹回。
- 边界情况：AI 面板与贴边竖条同屏共存（竖条本就贴边，不冲突）。
- 异常流：无。
- 依赖：FloatingNoteService 的 collapseWindow 既有能力。

### 功能名：首次配置

- 正常流：首次点圆钮 → 最小表单：Base URL、API Key、普通模型（必填），思考 / 视觉模型（选填，未配置时思考键隐藏、图片走普通模型）→ 保存（Key 加密）→ 直接进入输入框态。支持"测试连接"验证配置。
- 边界情况：填写一半取消 → 不保存半成品；Base URL 自动规范化（补协议 / 统一小写 / 去尾斜杠，已实现）。
- 异常流：Key 无效 → 对话错误提示中给出"检查配置"入口直达表单。
- 依赖：任务 1 已交付的设置与 SecretStore。

### 功能名：回答存为笔记

- 正常流：AI 回答末尾提供"存为笔记"入口 → 以回答全文创建普通笔记，进入现有列表，可置顶 / 编辑 / 回收站，与普通笔记同权。
- 边界情况：重复保存 → 各自独立笔记；超长照存，标题走 autoDeriveTitle 兜底。
- 异常流：保存失败 → Toast 提示，入口保留可重试。
- 依赖：NoteRepository 现有创建链路。

### 功能名：＋菜单·插入当前笔记

- 正常流：点「＋」→ 插入当前笔记 → 当前笔记正文以附件 chip 形式挂在输入框上方，可移除；随下一条消息发送作上下文。
- 边界情况：已附加 → 菜单项呈"已附加"态；无当前笔记 → 置灰。
- 依赖：FloatingNoteService 的 currentNoteId。

### 功能名：图片附件

- 正常流：＋ → 插入图片 → 系统相册选图 → 压缩（长边 ≤2048 JPEG）→ 缩略 chip 预览 → 随消息发送，请求自动改用视觉模型（未配置则普通模型）。
- 边界情况：单条 ≤3 张；纯图片可发送。
- 异常流：模型不支持 → 失败气泡提示"当前模型可能不支持图片"。
- 依赖：透明中转选图 Activity、多模态消息格式。

### 功能名：思考模式开关

- 正常流：默认关，点击开/关，状态可见并跨会话记忆；开启后请求改用"思考模型"；思考过程内容不展示，只展示最终回答。
- 边界情况：未配置思考模型 → 按钮隐藏；思考开启时附图 → 视觉模型优先（v1 不叠加）。
- 异常流：思考模型请求失败 → 同失败处理。
- 依赖：设置中的思考模型字段。

### 功能名：失败处理

- 正常流：请求失败 → 该条回答位置显示内联红调错误（原因 + 重试），笔记功能与已存笔记零影响。
- 边界情况：弱网 → 超时按失败处理；401/402/429 → 文案提示检查 Key / 额度。
- 异常流：重试仍失败 → 保留错误可继续重试或删除该轮。
- 依赖：无。

## 非功能需求

- 性能：笔记窗路径零额外开销；AI 三态出现 / 消失动画 ≤250ms 且不阻塞输入；后台生成不新增前台服务。
- 安全：API Key 加密存储；笔记内容仅在主动发送时出网；未配置 AI 时零网络行为。
- 合规：`INTERNET` 权限 + 明文流量放行（任务 1 已交付）；README 更新为"笔记纯本地，AI 需自配且仅使用时联网"。
- 平台：Android 8.0+（minSdk 26）。

## 明确不做的事

语音输入；文件上传；语义搜索；内置 AI 服务 / 账号 / 订阅；对话云同步；AI 自动改写用户笔记正文；把 AI 入口并入笔记窗工具栏（v1 方案已否决）。
